# Sagittary Wiki

This directory is the source of truth for gameplay and feature documentation.

Current pages:

- `arrow-components.md`: how the modular arrow system currently works
- `porting-1.21.1-to-26.1.2.md`: build and toolchain migration notes for the 26.1.2 line

Workflow:

1. Update docs here first.
2. Keep gameplay details aligned with the actual code.
3. If a GitHub wiki is later used, publish from these files instead of rewriting pages by hand.
