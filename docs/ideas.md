# Ideas Backlog

This file holds feature ideas that are intentionally not part of the current release baseline.

## Possible New Tips

- Diamond tip: partial armor piercing
- Netherite tip: stronger impact, possible shield-piercing or fire-resistant behavior
- Quartz tip: near-perfect accuracy and longer effective range
- Prismarine tip: stronger underwater behavior or aquatic tracking
- Obsidian tip: heavy impact, possible piercing or block interaction
- Explosive tip: TNT or end-crystal-inspired detonation concept
- Slime tip: bouncing or ricochet behavior

## Possible New Shafts

- Iron shaft: heavier, slower, harder-hitting
- Chorus shaft: random teleport effect on hit
- End rod shaft: glowing projectile or dark-range niche
- Bone shaft: lightweight skeletal-themed behavior

## Possible New Fletchings

- Dragon breath fletching: lingering cloud effect
- Shulker shell fletching: levitation effect

## Future Systems

- Quiver system for storing and selecting arrow variants
- Arrow retrieval or boomerang-style recovery behaviors
- Special combo bonuses for specific component pairings

## Technical Follow-Up Ideas

- Revisit copper lightning implementation to reduce hitching
- Keep mechanic docs in `docs/wiki/` as the code evolves
- Treat the future 1.21.1 downgrade as a separate migration effort from feature work
